# Programmazione Concorrente e Distribuita (PCD) — Assignments (a.y. 2025/2026)

Repository containing the assignments developed for the **"Programmazione Concorrente e Distribuita"** course (Master's Degree in Computer Science and Engineering — *Ingegneria e Scienze Informatiche*, University of Bologna, Cesena Campus).

## Repository Structure

Each assignment folder follows the deliverable layout required by the course:

```text
pcd-2025-2026-assignments/
├── assignment-01/
│   ├── src/          # Source code
│   └── doc/          # Report (report.pdf)
├── assignment-02/
│   ├── src/
│   └── doc/
├── assignment-03/
│   ├── src/
│   └── doc/
└── assignment-04/
    ├── src/
    └── doc/
```
